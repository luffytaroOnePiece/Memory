# MASTER PROMPT — High-Performance Interactive Nutrition Book

Create a **single self-contained `index.html` file** for a premium, modern, interactive **Human Nutrition Encyclopedia**.

The user will provide one food item:

**FOOD:** `[FOOD NAME]`

Your job is to research/analyze the food and generate a highly detailed nutrition profile specifically for **human consumption**.

The result must feel like a premium combination of:

* Modern nutrition encyclopedia
* Scientific food database
* Apple-style product page
* High-end health dashboard
* Interactive digital nutrition book

Do **not** create a basic blog page or simple table.

---

# 3. PERFORMANCE IS CRITICAL

The HTML must be optimized for performance.

Prioritize:

* CSS animations over JavaScript animations
* `transform` and `opacity` for animation
* Avoid layout thrashing
* Avoid unnecessary DOM manipulation
* Minimal JavaScript
* Lazy-load non-critical assets
* Use `content-visibility` where appropriate
* Use `will-change` sparingly
* Avoid huge images
* Avoid continuously running expensive animations

Animations should respect:

```css
@media (prefers-reduced-motion: reduce)
```

When reduced motion is enabled, disable non-essential animations.

Target:

* Fast initial rendering
* Smooth 60 FPS interactions
* Mobile-friendly performance
* No unnecessary dependencies
